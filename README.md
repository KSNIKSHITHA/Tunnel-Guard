# TunnelGuard AI
TunnelGuard AI is a prototype for safer underground metro excavation. 
Digging beneath a city can make the ground move, settle or become unstable, which puts tunnels and nearby buildings, roads and utilities.
Our miniature tunnel model uses an ESP32, an MPU6050 motion sensor, moisture, rain and gas sensors, and a potentiometer for threshold calibration. LEDs and buzzers give visual and audible warnings.
The web dashboard shows a risk score, alerts, a risk register and a response playbook for operators. It currently runs on simulated scenarios, with an ESP32 live-data link built in and ready to connect.
This is a monitoring demonstration, not a validated real-world tunnel safety system. Future work includes trend-based anomaly detection and validated geotechnical sensors.
