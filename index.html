Connection checklist

1
Connect your laptop to the ESP32 Wi-Fi SSID configured in the firmware.
2
Open this HTML dashboard in the browser and use http://192.168.4.1/data as the URL.
3
If connection fails, open the URL directly in a browser. If JSON does not appear, check the ESP32 Serial Monitor and wiring.
